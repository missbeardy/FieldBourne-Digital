# FieldBourne Digital

Marketing site for [fieldbournedigital.com.au](https://fieldbournedigital.com.au).

## Stack

Vite + React + TypeScript + Tailwind + Motion. Static build on GitHub Pages.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Brand
